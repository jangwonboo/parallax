# 개조식 — `nominal`

보고서식으로 통독하거나 발췌할 때 쓰는 문체다. `business`와 `literal`을 바탕으로 **종결부만** 갈아 끼운 것이며, 문장이 한자어 동사성 명사로 끝나는 것이 특징이다.

먼저 밝혀 둘 제약이 하나 있다. **소설에는 쓸 수 없다.** 서술은 어떻게든 되지만 대사가 전부 무너진다.

---

## 규칙

### ① 기본형은 한자어 동사성 명사

문장을 끝맺는 자리에는 다음과 같은 한자어 동사성 명사를 쓴다.

정의 · 실행 · 연구 · 관찰 · 제시 · 도출 · 검증 · 구성 · 전제 · 상정 · 부정 · 시도 · 필요 · 전환 · 유지 · 선택.

```
논증, 그리고 이 책은 두 부분으로 구성.
이후 뇌를 끊임없는 즉흥 연주자로 보는 긍정적 설명 제시.
이 책의 아이디어는 광범위한 출처에서 도출.
```

### ② `함·됨·임`은 없어도 뜻이 통하면 뗀다

명사형을 만들었더라도 접미사가 남아 있으면 문장이 늘어진다. 떼어도 뜻이 통하면 뗀다.

| | |
|---|---|
| 발명함 | → **발명** |
| 도출됨 | → **도출** |
| 구성됨 | → **구성** |
| 제시함 | → **제시** |
| 시도일 것임 | → **시도일 것** |

### ③ 끝맺는 명사 앞의 조사도 뗀다

조사를 살려 두면 개조식이 되지 않는다. 서술형 문장에서 종결어미만 떼어 낸 어정쩡한 형태로 남는다.

| | |
|---|---|
| 설명**을** 제시 | → **설명 제시** |
| 폐기**가** 필요함 | → **폐기 필요** |
| 제거하는 시도**를** 함 | → **제거 시도** |
| 두 부분으로 구성됨 | → 두 부분으로 **구성** |

여기에는 중요한 단서가 붙는다. **문장 중간의 조사와 연결어미는 정상 문어체 그대로 둔다.** 개조식으로 바꾸는 것은 끝맺음뿐이며, 문장 전체를 전보문처럼 만드는 것이 아니다.

### ④ 고유어 명사형은 대안이 없을 때만 쓴다

`함 · 됨 · 있음 · 없음 · 같음 · 보임 · 아님` 같은 고유어 명사형은 마땅한 한자어를 찾을 수 없을 때에 한해 쓴다.

```
성공 가능성이 희박.            ← 한자어가 있으므로 그것을 쓴다
가능성이 높음.                 ← 한자어가 없으므로 고유어 명사형
영화 세트와 같음.              ← 한자어가 없다
이것은 심리학 교과서의 이야기가 아님.
```

### ⑤ 시제와 상은 두 계열을 섞어 싣는다

`했음 / 되었음 / 할 것임 / 고 있음`은 **시제나 상을 반드시 실어야 할 때만** 쓴다. 현재 시제이거나 시제가 무관한 진술은 ①②③에 따라 명사로 끊는다.

```
오랫동안 탐구해왔음.               ← 과거·완료
경쟁하는 해석을 제시하고 논쟁할 것.   ← 미래
모든 것을 압도하는 중.             ← 진행
```

### ⑥ 계사문(A is B)을 체언 하나로 뚝 끊지 않는다

계사문을 명사로 끝내려다 보면 술어가 사라져 문장이 성립하지 않는 경우가 생긴다. `~에 해당` 또는 `~로 규정됨`으로 술어를 세우고, 부정이면 `~이 아님`으로 맺는다.

```
✗ 안나의 동기는 공백.
○ 안나의 동기는 공백에 해당.
✗ 내면 세계는 신기루.
○ 내면 세계는 신기루에 해당.
```

이때 `해당한다`나 `규정된다`로 쓰면 안 된다. 끝은 어디까지나 명사여야 한다.

### ⑦ 청유형·명령형 도입부는 조건절로 바꾼다

`Suppose`, `Imagine`, `Let us consider` 같은 도입부를 `~해 보자`로 옮기면 그 문장에서 개조식이 무너진다. 조건절로 바꾸어 문장을 이어 간다.

```
✗ 안나가 실존 인물이었다고 가정해 보자.
○ 안나가 실존 인물이었다고 가정할 경우, …
```

### ⑧ 물음표 문장과 인용문은 예외로 둔다

원문의 수사적 질문은 물음표를 살리되 `-일까?` 또는 `-인가?`로 끝낸다.

**인용부호 안은 손대지 않는다.** 대사는 인물이 실제로 입 밖에 낸 말이므로 개조식으로 바꿀 대상이 아니다.

```
그는 곧바로 펜과 메모지를 휘두르며 이렇게 말함.
"자, 카레니나 씨, 스스로를 허무 속으로 던지기로 결심한 이유를 조금 말씀해 주시겠어요?"
이 전략은, 완곡하게 말해도, 성공 가능성이 희박.
```

## 문장 분할과 축약

문장을 다루는 원칙은 다음과 같다.

- 원문의 순서를 유지한다. 영어 문장을 임의로 쪼개지 않는다.
- 다만 **한 문단 안에서** 짧은 문장을 하나로 축약하거나 중복된 수식을 덜어내는 것은 허용한다.
- **축약은 문단 경계를 넘지 못한다.** 경계를 넘는 순간 원문과의 대응이 끊어지고, 이후 어떤 단계에서도 복구할 수 없다.
- 축약은 덜어내는 작업이지 보태는 작업이 아니다. 원문에 없는 설명·비유·예시를 지어내지 않는다.

## 그 밖의 축

| 축 | 값 |
|---|---|
| 어휘 | 한자어 우선. 개념어는 학계 표준 역어를 쓰되, 원어가 이미 표준이면 억지로 번역하지 않는다 |
| 대명사 | 생략. `he/she/it/they`는 지시 대상이 모호해질 때만 명시 |
| 고유명사 | 인명·지명은 음차하고 첫 등장 시 원문을 괄호로 병기. 기업명·제품명·학술지명은 원문 그대로 |
| 1인칭 | 저자의 `I/we`는 무주어가 기본. 필요하면 "저자"로 옮긴다 |
| 목록 | 불릿·번호 목록은 병렬 구조를 살리고 항목의 끝을 명사형으로 통일 |
| 수치 | 숫자·단위·연도·통화·퍼센트는 절대 손대지 않는다 |

## 실측 자료 — 시작하기 전에 알아 둘 것

### 규칙을 여러 자리에 흩으면 무너진다

같은 원문 36문단·171문장을 대상으로 프롬프트 구성만 바꾸어 가며 `-다` 누출을 셌다.

| 프롬프트 구성 | 누출 |
|---|---|
| 종결 규칙을 **축 하나**에 ①②③으로 압축 | **1건** |
| 계사문·청유형을 별도 축으로 승격하고 `[절대 규칙]`에도 추가 | **54건** |
| 다시 압축형으로 되돌림 | **1건** |

두 번째 구성에서 시스템 프롬프트는 29.4k 토큰에서 33.3k 토큰으로 늘었다. 규칙을 더 강조하려는 의도였지만, 분량이 늘어난 만큼 정작 핵심 규칙이 다른 문장들 사이에 묻혔다. **여러 자리에 되풀이하는 것은 강조가 아니라 희석이다.**

### 실행마다 결과가 흔들린다

같은 프롬프트로 같은 원문을 세 번 돌렸을 때 누출이 1건, 15건, 1건으로 나왔다. 비율로는 0.6%에서 8.8% 사이다. 두 번째 실행에서 무엇이 달랐는지는 설명할 수 없다. 프롬프트만으로는 문체가 보장되지 않으므로 기계 검사를 반드시 붙인다.

### 누출은 긴 문단의 가운데에 몰린다

1,200자 12문장짜리 문단을 살펴보면 앞뒤는 명사형인데 중간 여섯 문장이 `이송된다 / 선택한다 / 높다 / 있다 / 남는다`처럼 서술형으로 풀려 있다. 모델이 긴 서사를 이어 가는 동안 규칙을 놓치는 자리다.

문단을 짧게 쪼개어 보내면 누출은 줄지만 호출 수가 배로 늘어난다. **샌 문단만 골라 다시 보내는 쪽이 싸다.** 실제로 전체의 10% 안팎만 다시 나간다.

## 검사와 교정

```bash
python scripts/check_endings.py 초고.md
python scripts/check_endings.py 초고.md --quiet    # 개수만 출력하고, 누출이 있으면 exit 1
```

검출기는 두 가지를 마스킹한다. 둘 다 마스킹하지 않으면 정상인 문장이 누출로 잡힌다.

- **인용부호 안.** 대사의 `-습니다`는 규칙상 정상이다. 마스킹하지 않으면 그 문장이 영원히 "아직 누출"로 남는다. 교정자는 규칙대로 대사에 손대지 않으므로 다시 요청해도 결과가 바뀌지 않기 때문이다.
- **`요`로 끝나는 명사.** `필요`·`중요`·`개요`·`수요` 같은 낱말이 걸리지 않도록 `요` 단독은 보지 않고 어미 형태(`-어요/-예요/-세요/-지요/-네요/-군요/-까요`)만 본다.

교정을 요청할 때 지켜야 할 원칙이 하나 있다. **교정은 재작성이 아니다.** 걸린 문단만, 그중에서도 종결부만 갈아 끼운다. 전체를 다시 쓰게 하면 문체는 고쳐지겠지만 어휘 선택이나 문장 구성처럼 손댈 필요가 없던 부분까지 함께 바뀐다.

그래서 교정 요청에는 다음 네 가지를 못 박아 둔다.

> 낱말을 바꾸지 마라. 어휘·어순·수식 관계는 그대로 둔다. 종결부만 손댄다.
> 문장을 합치거나 나누지 마라. 문장 수를 바꾸지 마라.
> 숫자·연도·단위·고유명사·인용 내용·각주 마커·강조 마크업은 100% 보존한다.
> 이미 명사로 끝난 문장은 한 글자도 고치지 말고 그대로 출력한다.

## 번역투 제거(deslop)를 걸지 않는다

개조식에는 번역투 제거를 태우면 안 된다. 교정 규칙표가 전부 `-다` 서술문을 전제로 작성돼 있기 때문이다. `~이 존재한다`를 `~이 있다`로 바꾸고, `~할 수 있을 것이다` 같은 조동사 중첩을 풀고, `~하는 것은 중요하다` 같은 형식주어를 걷어내는 규칙들은 모두 서술형 문장을 대상으로 한다.

이 규칙들이 명사형 종결을 번역투로 읽고 문장을 통째로 서술형으로 되돌린다. 그 결과 **문체 자체가 지워진다.**

개조식의 마무리는 번역투 제거가 아니라 위에서 설명한 종결 검사와 교정이 담당한다.
