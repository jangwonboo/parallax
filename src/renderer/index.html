기능 설명

읽기

왼쪽이 원문, 오른쪽이 번역이다. 한 단락이 한 행을 이루므로 좌우가 늘 맞물린다.

  • 가운데 손잡이를 끌면 좌우 폭이 바뀐다. 두 번 누르면 절반으로 돌아간다(조판 패널의 「좌우 폭 균등」과 같다).
  • 폭은 저장하지 않는다 — 시작은 언제나 반반이다.
  • 마우스를 올린 단락은 원문·번역 두 칸이 함께 밝아진다. 어느 것이 짝인지 눈으로 바로 찾으라는 표시다.
  • 드래그로 글을 고르면 시작한 쪽 대역만 잡힌다. 반대쪽 열이 끼어들지 않는다.

형광펜

글을 긁고 Alt+H. 칠한 것은 오른쪽 목록에 읽은 순서대로 쌓인다.

  • 원문과 번역은 서로를 모른다. 한쪽에 칠해도 반대쪽은 그대로다 — 낱말이 어디에 대응하는지 알 방법이 없기 때문이다. 두 쪽 다 칠하려면 두 번 긋는다.
  • 목록 항목을 누르면 그 자리로 간다. 오른쪽 🗑 로 하나씩 지운다.
  • 여러 개를 한 번에 다루려면 선택 을 누른다. 체크한 것만 지우거나(휴지통) Markdown 파일로 내보낸다(내려받기).
  • 이미 칠한 자리에 겹쳐 그으면 하나로 합쳐진다. 칠 하나에 목록 한 줄이 늘 맞물린다.
  • 번역을 다시 돌려 칠할 자리가 사라지면 목록에 「번역이 바뀌었습니다」 로 남는다. 지우지는 않는다.
  • 형광펜은 .parallax 안에 들어간다 — 파일을 옮기면 따라간다.

목차

  • 툴바 목차 로 연다. 부 > 장 > 절 세 단계까지 계층으로 접힌다.
  • 왼쪽 쐐기 를 눌러 가지를 접고 편다. 처음에는 두 단계까지 보인다.
  • 항목을 누르면 그 자리가 툴바 바로 아래 에 선다.
  • 읽는 자리가 저절로 강조된다. 접힌 가지 안으로 들어가면 그 가지가 펼쳐진다.
  • 넓은 화면에서는 목차가 본문을 밀어낼 뿐 덮지 않는다. 좁으면 겹쳐 뜨고, 항목을 고르면 닫힌다.

조판

툴바 조판. 결과가 본문에 바로 보이므로 슬라이더를 움직이며 맞추면 된다.

  • 배치 — 원문 왼쪽 · 번역 왼쪽. 번역을 주로 읽고 원문을 곁눈질한다면 번역을 왼쪽에 둔다.
  • 글꼴 — 영문과 한글을 따로 고른다.
  • 글꼴 크기 10~24pt · 줄간격 5단계 · 단락간격 3단계 · 본문 폭.
  • 단락간격을 주면 첫 줄 들여쓰기는 자동으로 빠진다 — 단락을 나누는 장치는 하나면 된다.

사전

  • 원문의 낱말을 두 번 누르면 영한·영영 뜻이 뜬다. 한 번 누르는 것으로는 뜨지 않는다 — 글을 짚어 보려는 선택마다 사전이 따라 뜨면 본문을 가린다.
  • 하이픈·아포스트로피가 든 낱말은 통째로 잡힌다(self-aware · don't).
  • 밖을 한 번 누르거나 Esc, 또는 스크롤하면 닫힌다.

번역

  • 눈이 머무는 장 전체를 번역한다. 보이는 단락이 먼저다.
  • 아직 오지 않은 칸은 회색 자리로 남는다.
  • 책 전체를 한 번에 번역하는 것은 스킬 CLI 몫이다 — 문서를 열 때마다 전량 번역이 돌면 돈이 샌다.

내보내기

파일 → Markdown 내보내기 는 영문·한글 두 파일을 낸다. 밖으로 가져가는 글은 한 언어로 읽는 글이기 때문이다. 머리글(#·##·###)은 목차와 같은 구조로 붙는다.
